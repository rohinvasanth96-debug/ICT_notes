**Tuple Fn**
	• Tuple structure()
	• no change available(immutable)
	• If we need to change in tuple we need to change to list and make changes and convert back 
      to tuple
	

**List Fn**
	• List structure []
    • Can add any data types inside
	• Elements seperated by comma
	• Len fn in list will return no of elements
    • List Fns- append,copy,clear,pop,count,index,remove, reserve,sort , extend

**Dictionary Fn**
    • Dictionary structure {}
    • It has no index but has keys
    • Keys should be unique
