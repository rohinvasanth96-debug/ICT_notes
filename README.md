# ICT_notes
Notes of ICT class 1-9

**Keyboard Shortcuts**

	• Power user menu- Win + x
	• Minimize- alt + esc
	• Switch tab- win + tab (or) alt + tab
	• Run - win + R
	• Voice typing - win + H
	• Emoji - win + .
	• Win recording - win +alt +r
	• Select text letter by letter- shift + arrow
	• Select word by word- shift + cntrl + arrow
	• Select word- mouse double click
    •   Select line - triple mouse click
